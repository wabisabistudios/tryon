# Try-On — Shot List (everything the page needs)

Shoot once, in studio light, same session. Consistency across these frames is what
makes the page look expensive.

## A. Demo hand set (hero slider) — the one non-negotiable
One model hand, locked camera position (tripod, mark the hand position with tape).
- `hero-before.jpg` — bare, clean, buffed nails. Palm down, plain surface (ivory/ink card as background), soft window light.
- Then WITHOUT moving camera or hand position: paint or press-on 3–4 sets and reshoot each:
  - `hero-cherry.jpg` (Cherry Noir), `hero-french.jpg`, `hero-chrome.jpg`, `hero-marigold.jpg` (Marigold Line)
- Because the frames align, the drag-slider reads as one hand transforming — this is the whole hero.
- Alternative: shoot only `hero-before.jpg` and run it through the real pipeline for the afters. Cheaper, and it honestly demos the actual product quality.
- Crop 4:3, ≥1600px wide. Drop into `assets/tryon/`.

## B. Proof strips (result page, per design)
Real client sets already painted in the chair — 2–3 photos per design you offer.
- Path convention: `assets/tryon/proof/<designId>-1.jpg`, `-2.jpg`, `-3.jpg`
  (designIds: cherry-noir, milk-glaze, classic-french, micro-french-marigold, chrome-silver,
  cat-eye-emerald, latte-ombre, terracotta-matte, marigold-line, ink-dots, glitter-champagne, tortoise-shell)
- Portrait-ish crop, hands only, studio context visible at the edges (towel, lamp) — proof, not stock.
- The strip auto-hides for any design with no images yet, so ship incrementally.

## C. Model video (you offered — use it as the ad, not on the page)
15–20s vertical reel, the page's own loop:
1. Model photographs her hand on her phone (2s)
2. Screen recording: swatch wall tap → nail painting itself (3s)
3. The drag-slider moment on HER hand — finger dragging bare→rendered (4s, the money shot)
4. Slot tap → "Held." with petals (3s)
5. Cut to the real chair: technician painting the same design, record open on the phone beside (5s)
End card: "Any design · ₹2,999 · basedaesthetics.co/tryon"
That video IS the Meta creative for the campaign — the page and the ad teach the same gesture.

## D. Optional polish
- 3–4 studio/team frames for a trust strip if we add one later (autoclave, sealed tools opening — your existing authority imagery works).
- A phone-held "record" screenshot for OG/social preview image.
